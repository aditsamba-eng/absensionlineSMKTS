Integrasi Google Spreadsheet

Hubungkan aplikasi presensi ini ke Google Sheet sekolah Anda agar data otomatis tersimpan di cloud.

Masukkan Web App URL yang didapatkan setelah melakukan deploy Apps Script.

Panduan Membuat Google Apps Script (Gratis)

  1. Buka Google Sheets dan buat spreadsheet baru dengan nama "Presensi SMK Taruna Satria".
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua kode bawaan dan tempelkan kode Apps Script berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (data.action === "sync_absensi") {
    var rows = data.payload;
    rows.forEach(function(r) {
      sheet.appendRow([
        r.waktu,
        r.tanggal,
        r.nis,
        r.nama,
        r.kelas,
        r.jurusan,
        r.status,
        r.catatan
      ]);
    });
    return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik Deploy > New deployment.
  2. Pilih tipe: Web app. Set Who has access menjadi: Anyone.
  3. Klik Deploy, berikan izin akses Google, lalu **Copy Web App URL** dan tempel pada kolom input di atas.
